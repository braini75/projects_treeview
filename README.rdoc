= Redmine Plugin: projects_treeview

A collapsible tree view for browsing Redmine projects and their subprojects.

== Origin
This plugin is a fork of {projects_treeview}[https://github.com/braini75/projects_treeview]
by Thomas Koch (braini75), which is itself an adaptation of the original
"projectstreeview" plugin by <b>Paul Kertscher</b> (2014,
{sourceforge}[http://sourceforge.net/p/projectstreeview/code/HEAD/tree/trunk/],
version 0.0.3-78). All credit for the original idea and implementation goes to
them. Their MIT copyright notices are kept (see License and References).

== Features
* A page that lists the projects visible to the current user, nested by project
  hierarchy. Folders expand and collapse with a click or from the keyboard.
* Menu entry in the top menu, next to "Projects".
* Respects Redmine permissions: only projects the user can see are listed. A
  subproject whose parent is not visible to the user is shown at the top level.
* Sidebar option "View closed projects"; closed projects are dimmed.
* Follows the active Redmine theme: no images and no hardcoded colors.
* Translations: English, English (GB), German and Spanish. Other languages fall
  back to English.

== Requirements
* Redmine 5.0 or higher. Maintained for Redmine 7.x.
* No database migration and no extra gems.

== Installation
1. Go to the plugins directory of your Redmine and clone the repository:
    cd {REDMINE_ROOT}/plugins
    git clone https://github.com/sostenido/projects_treeview.git
2. Restart Redmine (the plugin's assets are picked up on restart). With Docker,
   the plugin folder must be in the mounted plugins volume (or copied into the
   image); then restart the container.
3. Done. There is nothing to migrate: the plugin does not touch the database.

== Usage
1. Click "Projects treeview" in the top menu, next to "Projects".
2. Click a folder (anywhere on its row except the name) to expand or collapse it;
   click a project name to open the project.
3. To include closed projects, tick "View closed projects" in the sidebar and
   press "Apply".

== Upgrading from 0.4.x
Nothing to migrate. The markup changed from <tt>ol.tree</tt> to
<tt>ul.projects-tree</tt> and the bundled icons are gone; if you styled the old
tree from a theme, update your selectors.

== Tests
From the Redmine root:
  bundle exec rake redmine:plugins:test NAME=projects_treeview RAILS_ENV=test

== Changelog
=== 0.5.0
* Security: project names are now HTML-escaped. The tree previously inserted them
  unescaped, so a malicious project name could run script in other users' browsers.
* Valid HTML: nested lists built on <details>/<summary>; the checkbox/CSS hack
  is gone, so the tree is also keyboard accessible.
* Links use <tt>project_path</tt> instead of hand-built URLs.
* Closed projects are dimmed when "View closed projects" is checked.
* No images and no hardcoded colors: the tree follows the active Redmine theme.
* Added Spanish translation, an empty-state message and a page title.
* Simplified the controller (removed unused helper includes).
* Real functional tests (they replace the placeholder test).
* Declares <tt>requires_redmine</tt> (5.0 or higher).
* Added the LICENSE file.

=== 0.4
* Support for Redmine 5.x.
